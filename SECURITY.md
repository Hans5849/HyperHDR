# Security policy

This repository is a public fork of [awawa-dev/HyperHDR](https://github.com/awawa-dev/HyperHDR). Its focus is the Orange Pi 5 Plus (RK3588) HDMI → WLED pipeline.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

- **Code or workflows changed in this fork:** report privately through GitHub's private vulnerability reporting on this repository (**Security → Report a vulnerability**).
- **Code inherited unchanged from upstream:** report it to the upstream project following its own security policy.

Please include the affected version or commit, your environment, the steps to reproduce and the impact. We aim to acknowledge reports within 7 days.

## Supported versions

Only the latest commit on `master` of this fork is supported. No release from this fork is security-supported yet.
